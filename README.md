Typewright.
A single-file typing test with bot races, weak-key drills and result cards worth posting.

index.html — that's the whole app.

Why
Most typing tests look like dashboards. This one looks like a letterpress shop —warm paper, a red rubber stamp that slams your level onto the results, and aledger that remembers everything you do.

Features
3 levels — easy (quotes & prose), medium (hard words), hard (prose + code)
Drill mode — auto-targets your statistically worst keys
Bot races 1v1–1v4 — bots tuned to your skill, first-to-N-words
Pass-and-play PvP — 2–4 players, same words, one keyboard
The Ledger — best WPM, accuracy, streaks, races won — all in localStorage
14 achievements and a per-key error heatmap
Result cards — download any run as a 1200×630 PNG
Synthesized typewriter sounds · zero dependencies · zero tracking
Run it
git clone https://github.com/YOUR_USERNAME/typewright.gitopen typewright/index.html   # or just double-click it
Or deploy to GitHub Pages: push to main, thenSettings → Pages → Deploy from branch → main / root.

Scoring
net wpm  = (correct chars ÷ 5) ÷ minutesaccuracy = correct keystrokes ÷ total keystrokes
Standings: Beginner <30 · Intermediate <45 · Advanced <60 · Expert <80 · Master 80+

Shortcuts
Tab/Esc restart · Enter rerun same words · Ctrl+Backspace clear word
